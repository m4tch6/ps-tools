# ツールのカケラ

回転率の計測と、機種別の設定判別をまとめたツール集。
すべて 1 ファイルの静的 HTML なので、GitHub Pages にそのまま置くだけで動きます。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | ポータル（トップページ） |
| `kaiten/` | 回転率計算（パチンコ） |
| `garupan/` | ガルパン最終章 設定判別 |
| `starlight/` | レヴュースタァライト 設定判別 |
| `kyokou/` | L虚構推理 設定判別 |
| `rk-lines.txt` | RKちゃまの台詞 |
| `rk.png` | RKちゃまの立ち絵 |

## RKちゃまの台詞を増やす・変える

`rk-lines.txt` を**1 行に 1 台詞**で書くだけです。行数に制限はありません。
前後の `「」` は表示時に自動で外れるので、付けても付けなくても構いません。

トップページを開いたときと、7 秒ごと、そして RKちゃまをタップしたときに
ランダムで 1 つ選ばれます。同じ台詞が続けて出ないようにしてあります。

> `index.html` の中にも同じ台詞の控えが入っています。これはサイトを
> サーバーに置かずファイルを直接開いたときの保険で、`rk-lines.txt` が
> 読めた場合はそちらが優先されます。普段は txt だけ編集すれば大丈夫です。

## 入力の保存について

各ツールは入力内容を `localStorage` に自動保存します。
スマホで他のアプリに切り替えてブラウザのタブが破棄されても、次に開いたときに続きから再開できます。

保存キーはツールごとに分かれています。

| ツール | キー |
|---|---|
| 回転率メーター | `kaiten_session_v1`（作業中の画像・基準線）<br>`kaiten_records_v1`（記録タブ） |
| ガルパン | `garupan_v1` |
| スタァライト | `starlight_v1` |
| 虚構推理 | `kyokou_suiri_v1` |

`localStorage` は**オリジン（ドメイン）ごと**に保存されます。
公開先の URL が変わると以前のデータは読めなくなるため、URL が固定される GitHub Pages を使ってください。

## 更新のしかた

ファイルを書き換えて push すると、1〜2 分で公開ページに反映されます。

```bash
git add -A
git commit -m "update"
git push
```

## 注意

- 設定判別の推定値は各解析サイトの公開値に基づく参考値です。
- JSX の変換にブラウザ上の Babel を使っています。`<script type="text/babel">` の中で
  JSX を書くときは `/* @jsxRuntime classic */` が必要です（Babel 8 の既定は自動ランタイムで、
  `import` 文が生成されて動かなくなるため）。
